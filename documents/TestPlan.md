# TEST PLAN - Hệ thống kiểm tra chống chỉ định thuốc

## 1. Mục tiêu kiểm thử

Đảm bảo hệ thống hoạt động đúng các chức năng chính bao gồm đăng ký, đăng nhập, quản lý thuốc, quản lý bệnh nền, kiểm tra chống chỉ định, kiểm tra tương tác thuốc, gợi ý thuốc thay thế và lưu lịch sử tra cứu.

## 2. Phạm vi kiểm thử

- User Account
- Drug Management
- Disease Management
- Contraindication Check
- Drug Interaction Check
- Recommendation System
- History Management
- Frontend UI
- Deployment

## 3. Loại kiểm thử

- Kiểm thử chức năng
- Kiểm thử API
- Kiểm thử giao diện
- Kiểm thử dữ liệu đầu vào
- Kiểm thử tích hợp
- Kiểm thử hệ thống
- Kiểm thử chấp nhận người dùng

## 4. Công cụ kiểm thử

- Swagger
- Trình duyệt Chrome
- SQL Server
- GitHub
- Jira

## 5. Tiêu chí hoàn thành

Hệ thống được xem là hoàn thành khi các chức năng chính chạy đúng, dữ liệu được lưu vào SQL Server, giao diện hiển thị ổn định và không phát sinh lỗi nghiêm trọng trong quá trình demo.
